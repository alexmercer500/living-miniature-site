## Visual inspection

Both images have no visible text or watermark. Main rooflines and mandap
canopies are flat. They have distinct door framing, floral garlands, brass
lamps, warm sandstone, and a central mandap. Some small background openings
have decorative carved bracket profiles; inspect these at full size during
review against the architecture constraints.

The portrait leaves a generous sky area above the mandap. The desktop expands
the courtyard horizontally. Final HTML text placement, contrast, viewport
cropping, and navigation clearance still require browser review after
integration.

Source PNG files are approximately 3 MB each. Do not serve these source files
directly as production hero assets. Optimize only after visual selection.
